## ✨ Tentang Project

Website statis romantis tentang **Zahra Nur'Aeni** — bentuk apresiasi kecil atas kehadiran, kesabaran, dan rasa aman yang ia bawa.

> *"She makes ordinary days feel special."* — `index.html`

Tanpa framework, fokus tipografi bersih dan nuansa pink–purple hangat. **Siap deploy ke GitHub Pages** ( `index.html` ada di root ).

## 🛠️ Tech Stack

HTML5 + CSS3 (Custom Properties, Flexbox, Grid) + Google Fonts [Poppins](https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;600;700&display=swap) — No JS, No Build Step.

## 🚀 Cara Menjalankan

```bash
git clone https://github.com/<username>/love.git
cd love
# buka langsung
open index.html
# atau live server
npx serve .
python -m http.server 8000
```

Buka `http://localhost:8000`

## 🎨 Design Tokens (`css/style.css:3`)

`--primary #e91e8c` → `--secondary #9c27b0` gradient, `--dark #1a1a2e`, `--light #fef6fb`, `--radius 16px`, bg `linear-gradient(135deg, #fef6fb 0%, #f3e5f5 50%, #fce4ec 100%)`

## 🌍 Deploy GitHub Pages

1. Push repo → Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `root` → Save
2. Tunggu 1-2 menit → buka `https://<username>.github.io/love/`
3. Sudah fix: `index.html` di root, path CSS `css/style.css`, page di `page/`, img di `img/` (case-sensitive sudah dibetulkan `g5.jpg`)
